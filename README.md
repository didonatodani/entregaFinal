# Proyecto Final - Curso de Desarrollo Web de Coderhouse

Este proyecto fue desarrollado como parte del curso introductorio de Desarrollo Web en Coderhouse. Es una página web diseñada y maquetada con HTML, estilizada con CSS y SASS, y utilizando Bootstrap para diseño responsive. El sitio está alojado en GitHub Pages para acceso público.

## Características

### 1. **Estructura**
- **HTML:** Se utilizó un maquetado limpio y semántico para garantizar accesibilidad y SEO básico.
- **Componentización:** Se implementaron buenas prácticas para la organización del contenido.

### 2. **Estilo**
- **CSS & SASS:** Los estilos fueron desarrollados utilizando SASS para una mayor modularidad y reutilización del código.
- **Bootstrap:** Se aplicó Bootstrap para crear un diseño responsive y profesional.
- **Responsive Design:** Adaptación total a diferentes dispositivos mediante el uso de grids y flexbox.

### 3. **SEO**
- Metadatos básicos incluidos en las páginas.
- Correcto uso de etiquetas semánticas para mejorar la indexación en motores de búsqueda.

### 4. **Hosting**
El proyecto está alojado en GitHub Pages para garantizar acceso público.
